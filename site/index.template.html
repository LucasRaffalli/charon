« charon est endommagé et ne peut pas être ouvert » ? L'app n'est pas cassée : elle n'est pas notarisée Apple, et macOS bloque par défaut les apps téléchargées non notarisées (le clic droit → Ouvrir ne suffit pas pour ce message). Après avoir glissé charon dans Applications, lance une seule fois dans le Terminal : xattr -cr /Applications/charon.app puis ouvre l'app normalement. Les mises à jour suivantes s'installent automatiquement depuis l'app, sans refaire cette manipulation.
